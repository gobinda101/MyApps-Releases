# 🛠️ HtmlRun
**High-performance web runtime and IDE for mobile-first development.**

## 🌟 Key Features
- ✍️ **Intelli-Editor**: Full-featured IDE with advanced syntax parsing for HTML/CSS/JS.
- 🚀 **Turbo Engine**: Rapid local rendering of web projects.
- 🌉 **System Bridge**: Securely expose Android primitives to the JavaScript runtime.
- 🎨 **Dev Dashboard**: Modern Material 3 dashboard for project management.
